# StudyMind——基于大模型的个性化 AI 学习助手

## 应用方案文档

> 23 级人工智能专业课程设计项目 · 朱晨馨、游星宇
> 核心创新：基于知识图谱的个性化学习路径动态调整（GraphRAG）

---

## 一、项目背景与痛点分析

### 1.1 项目背景

随着国家教育数字化战略的深入实施与 AIGC 技术的爆发式发展，高等教育正加速从"标准化教学"走向"个性化学习"。一方面，高校课程（尤其是人工智能、计算机等理工类专业）教材知识密度高、课程节奏快，学生对课外的自主学习和复习需求强烈；另一方面，慕课、电子教材、网盘资料等数字化学习资源空前丰富，但资源数量与学习效果之间并未形成正比——"收藏即学会"成为普遍困境。与此同时，以 DeepSeek 为代表的大语言模型在语义理解、逻辑推理与结构化生成能力上实现跃升，为"AI 从内容生成器升级为学习教练"提供了坚实的技术底座。

StudyMind 正是在这一背景下立项：以教材为入口，以大模型为核心引擎，构建"解析—成图—规划—练习—诊断—调整"的个性化学习闭环，让每位学生拥有一位随叫随到、因材施教的 AI 学习教练。

### 1.2 痛点问题

**（一）资料繁杂、知识碎片化，难以构建体系。** 教材内容分散在纸质书、PDF、PPT、网课等多源载体中；学生在备考复习时往往只能逐页翻阅、零散记忆，缺乏对"知识点—前置关系—后继关系"的整体认知，学完一章仍不知其在整个知识体系中的位置，复习时"只见树木、不见森林"。

**（二）传统刷题盲目、缺乏针对性，无法精准定位薄弱点。** 题海战术是当前备考的主流方式，但海量练习无法回答三个关键问题：我哪里弱？为什么弱？下一步该练什么？错题本依赖手工整理，既低效又缺乏对错误根因的深层分析，"错了还错"的现象普遍存在。

**（三）学习路径僵化，无法随个人掌握情况动态调整。** 无论是课表、教材目录还是普通学习 App 的固定计划，本质上都是"统一进度条"：所有学生按同一顺序、同一节奏推进，无法根据个体掌握度差异进行动态调整。学习计划一旦生成便"一成不变"，与"因材施教"的教育理想相去甚远。

**小结：** 三个痛点指向同一核心矛盾——现有工具只是"内容的搬运工"，而非"学习的教练"。StudyMind 的立项目标即为解决该矛盾：用知识图谱解决"体系"问题，用 Elo 掌握度模型解决"定位"问题，用 GraphRAG 诊断解决"动态调整"问题。

### 2.3 非功能需求

- **性能**：提交答案接口 1 秒内返回判分结果（实测 0.02 秒量级）；出题、诊断、总结等 LLM 密集型操作全部走异步任务 + 前端轮询，主线程零阻塞；题库预生成与复用策略保证题目秒开。
- **可用性**：异步任务全程进度反馈；加载失败可重试、不白屏；答题状态机（待加载→答题→判分→总结）逻辑闭环，按钮永不"转圈卡死"。
- **安全**：判分答案仅存服务端、答题接口不出答案，杜绝前端作弊；API 密钥经 `.env` 注入、不入代码库；接口请求校验完备。
- **成本**：题库复用（该用户未答过的题直接复用）、题干向量去重、预生成限量三重策略控制 LLM 调用成本。
- **可扩展**：模块化单体架构；任务管理器为内存实现、接口签名与 Celery+Redis 一致，可平滑替换；三库分立（PG 事实源 / Neo4j 图谱 / Chroma 向量），可独立扩容。

### 3.2 系统架构设计

系统采用分层架构，自上而下分为四层：

- **表现层**：Vue3 单页应用，五大页面（知识库管理、知识图谱、学习计划、答题练习、掌握度看板），通过 RESTful API 与后端交互；异步任务统一通过轮询 `/api/task_status/{id}` 获取进度。
- **业务逻辑层**：FastAPI 接口层 + 服务层（教材解析 parser、知识构建 knowledge、计划生成 plan、出题判分 quiz、诊断引擎 diagnostic）+ 异步任务管理器 taskman（内存注册表 + 后台线程执行）。所有 LLM 密集调用均在后台线程执行，接口即时返回 `task_id`，保证前端永不阻塞。
- **数据层**：三库分立——PostgreSQL 存储业务事实（教材、知识点、题目、答题记录、掌握度状态），Neo4j 存储知识图谱（知识点的前置/关联关系，支撑邻域检索与可视化），ChromaDB 存储教材切片的 BGE-M3 向量（支撑 RAG 检索）。
- **AI 服务层**：DeepSeek 大模型负责知识抽取、出题、诊断、批改等生成任务（统一封装结构化输出）；BGE-M3 本地嵌入模型负责向量化；OCR 引擎兜底扫描件解析。

### 3.3 核心技术方案

**（1）教材解析与 RAG 检索增强生成**

教材上传后进入多策略解析链：优先 PyMuPDF 提取文本，失败则逐级降级 pdfplumber、pypdf；对无文本层的扫描版教材，自动触发 Tesseract OCR（中文 chi_sim，150dpi），实测可完整解析 300 余页扫描教材；解析时优先利用 PDF 书签（TOC）组织章节结构。随后将章节内容按语义切分为 chunk，经 BGE-M3 本地嵌入后存入 ChromaDB。出题、诊断、AI 助教等场景需要教材依据时，向量召回相关 chunk 注入提示词，实现"有据可依"的检索增强生成，有效抑制大模型幻觉。

**（2）知识图谱构建与可视化**

LLM 对解析后的教材内容进行结构化抽取，输出知识点实体（名称、定义）与实体间关系（前置、关联），并支持"无教材模式"——用户无 PDF 时直接由 LLM 按学科主题生成知识骨架。抽取结果双写 PostgreSQL（事实源）与 Neo4j（图存储）。前端基于 AntV G6 渲染交互式知识图谱，支持缩放、拖拽、节点聚焦，直观呈现知识体系全貌。

**（3）基于 Elo 模型的掌握度评估与动态路径调整【核心】**

**① Elo 掌握度模型。** 系统为每个"用户—知识点"对维护掌握度分值 θ（初始 1500），每次答题按 Elo 公式更新：答对概率 P = 1/(1+10^(-(θ-β)/400))，其中 β 为题目的难度映射值；答对则 θ += K(1-P)，答错则 θ -= K·P（K=32）。项目专门解决了题目难度 1~5 与 θ 量纲不匹配导致的"答对几乎不涨分"问题（difficulty_to_elo 映射）。掌握度同时受连对约束：连续答对 ≥3 或 θ ≥ 1700 即判定"已掌握"，自动跳过计划中该知识点的剩余任务。

**② GraphRAG 错题诊断。** 学生答错后，系统自动触发异步诊断任务：以错题知识点为中心，在 Neo4j 中检索其图谱邻域，结合该生全部知识点的掌握度分布，交由 LLM 进行根因分析，输出补学路径（前置知识点链条）与易混淆概念对，落库为诊断报告。

**③ 学习路径动态重排。** 诊断报告自动驱动计划调整引擎：补学路径中的前置知识点若不在计划中则插入"学习"任务，排期靠后则提前至当前日；易混淆概念插入"对比复习"任务；插入遵循"每日任务上限均衡"策略，防止某天任务堆积。

**④ 自适应出题闭环。** 下次出题时，出题服务读取该知识点最新诊断报告，按其策略个性化调整题目难度、认知层次（Bloom 分类）与干扰项设计，形成"答错→诊断→重排→降难度→再练→掌握"的完整闭环——这正是本项目区别于传统题库类产品的核心创新。

## 四、作品功能说明与 AI 核心作用

### 4.1 教材上传与智能解析

**功能概述：** 用户在首页上传 PDF 教材（或直接输入学科主题进入"无教材模式"），系统在后台自动完成解析、抽取与入库，全程以进度条 + 阶段提示（预计剩余时间）反馈。

**AI 大模型的核心作用：**

- **多策略解析引擎**：以 PyMuPDF 为主干，逐级降级 pdfplumber、pypdf，保证普通电子版教材的稳定解析；对无文本层的扫描版教材，自动触发 Tesseract OCR（中文 chi_sim，150dpi）兜底——实测可完整解析 300 余页扫描教材，PDF 书签（TOC）优先用于组织章节结构。
- **语义切分与向量化**：章节内容按语义切分为 chunk，经本地部署的 BGE-M3 嵌入模型向量化后存入 ChromaDB，为后续出题、诊断、答疑提供"有据可依"的检索基础。
- **LLM 结构化知识点抽取**：大模型从教材内容中识别知识点实体（名称 + 定义），经结构化输出约束（function_calling）保证格式稳定，去噪去重后双写 PostgreSQL 与 Neo4j。
- **无教材模式**：用户没有 PDF 时，只需输入学科与主题，LLM 即可直接生成知识骨架，零门槛建库。

### 4.2 知识图谱生成

**功能概述：** 系统自动构建"知识点 + 前置/关联关系"的知识图谱，前端基于 AntV G6 渲染，支持缩放、拖拽、节点聚焦，薄弱知识点以红色高亮。

**AI 大模型的核心作用：**

- **关系分析与抽取**：LLM 在抽取知识点时同步推理知识点间的**前置关系**（学习 B 必须先掌握 A）与**关联关系**（概念相近、易混淆），输出结构化三元组写入 Neo4j——这是普通"关键词列表"工具做不到的语义理解能力。
- **图谱即检索源**：知识图谱不是静态装饰品，它是错题诊断（GraphRAG）的邻域检索基础：学生答错时，系统沿图谱的边定位"该补哪些前置知识点"。
- **交互式可视化**：图谱页面支持点击节点查看定义、定位薄弱点分布，让"知识体系"从抽象概念变为一眼可见的拓扑结构。

`[此处插入：知识图谱可视化截图]`

### 4.3 学习计划与智能出题

**学习计划——双引擎生成：**

- **算法定结构**：系统对知识图谱执行拓扑排序，依据前置关系确定学习顺序，从根上保证"不会出现没学前置就学后继"的计划缺陷；
- **LLM 写文案**：大模型为每天的学习任务撰写贴合知识点内容的任务说明，使计划可读、可执行；
- **参数化定制**：用户设定总天数、每日学习时长与每日任务上限，计划按天拆分并跟踪 pending/done 状态。

**智能出题——AI 大模型的核心作用：**

- **复用优先、成本可控**：该用户未答过的题库题目直接复用；不足时才调 LLM 生成（3 路并发提速），并注入"已出题干 + 向量去重门禁"防止题目雷同；
- **自适应出题**：出题前读取该知识点最新诊断报告，个性化调整题目难度、认知层次（Bloom 分类）与干扰项设计；
- **题型丰富、判分严谨**：支持单选、多选、判断、填空与简答；客观题服务端规则判分、主观题 LLM 按评分细则逐点批改并给出评语；答案永不返回前端，杜绝作弊。

### 4.4 掌握度看板

**功能概述：** 看板以图表形式展示每个知识点的 Elo 掌握度、连续答对数、答题统计与最近复习时间，按掌握度排序并标红薄弱点，与顶部激励统计栏（连续打卡、今日学习时长、目标进度）全页面实时联动。

**AI 大模型的核心作用：** 看板数据不是简单的"对错计数"，而是 Elo 模型的**掌握度连续状态**——每题判分后即时更新（接口亚秒返回），掌握度变化（θ 前→后）逐题可追溯；答错触发 AI 诊断后，诊断结论与计划调整记录也会在看板与答题页同步呈现。

### 4.5 创新功能：个性化学习路径动态调整（GraphRAG）【核心创新点】

传统题库类产品止步于"判对错 + 看解析"，学习计划是静态的。StudyMind 的差异化在于：**AI 不仅告诉学生"错了"，还自动分析"为什么错、该补什么"，并动手重排学习计划**，形成完整闭环：

1. **答错即触发（不阻塞）**：判分接口亚秒返回对错与 Elo 变化；同时后台异步启动诊断任务，学生继续答题，绝不卡顿。
2. **GraphRAG 检索**：以错题知识点为中心，在 Neo4j 中检索其图谱邻域（前置/关联节点），并结合该生全部知识点的掌握度分布（θ 图谱）拼装诊断上下文。
3. **LLM 根因诊断**：大模型基于检索上下文输出结构化诊断报告：错误根因、补学路径（前置知识点链条）、易混淆概念、下次出题策略。
4. **计划自动重排**：诊断报告驱动调整引擎——补学路径中的知识点不在计划则**插入学习任务**、排期靠后则**提前**；易混淆概念**插入对比复习任务**；并遵循每日任务上限均衡策略防止任务堆积。
5. **自适应再练至掌握**：下次出题按诊断策略降低难度、调整认知层次；当该知识点 θ ≥ 1700 或连续答对 ≥3 时判定"已掌握"，计划中剩余任务自动跳过。

**案例演示**：学生在"OSI 参考模型"上答错，θ 由 1468.5 降至 1445.3；AI 沿图谱诊断发现其根因是前置知识点"网络分层思想"未掌握，自动在当日计划中插入补学任务并生成对比复习题；学生补学后再练，θ 回升并达标，系统跳过后续重复任务。

## 五、使用说明与交互指南

### 5.1 新用户入门流程

**① 注册/登录。** 打开 StudyMind，注册并登录账号（课程设计演示版本内置演示账号，可直接登录）。

**② 创建知识库。** 进入首页，选择一种建库方式：
- **方式 A（推荐）**：点击"上传教材"，选择 PDF 文件；
- **方式 B**：无教材模式——输入学科与主题（如"数据结构 · 二叉树"），AI 直接生成知识骨架。

**③ 等待 AI 解析。** 上传后页面显示解析进度与预计剩余时间，期间可自由浏览其他页面；解析完成后自动跳转知识图谱。

**④ 浏览知识图谱。** 查看自动生成的知识点与前置/关联关系，确认知识库构建成功。

进入首页 → 点击"上传教材"→ 选择 PDF → 等待解析进度完成 → 点击"查看图谱"→ 缩放、拖拽浏览知识体系 → 点击任意节点查看该知识点的定义与关联。

## 六、应用前景与商业模式

### 6.1 应用前景

**（1）高校教育领域。** 高校课程（尤其理工科）教材统一、知识体系标准，是 StudyMind 最直接的落地场景。学生期末复习、教师课后练习布置、补考/重修辅导等环节均可受益；系统积累的班级级掌握度数据还可反哺教学——教师据此发现普遍薄弱点，动态调整授课节奏。

**（2）职业培训领域。** 职业培训（IT 技能、资格考试、企业内训）知识更新快、学员基础差异大，对个性化培训的需求最为迫切。StudyMind 的"上传讲义→生成课程图谱→自适应练习"流水线可显著降低培训机构的教研成本，让培训师从出题、批改中解放出来。

**（3）终身学习领域。** 随着 AIGC 内容爆炸，"学什么、怎么学、学得如何"成为每个终身学习者的共同问题。StudyMind 提供的知识体系构建与动态学习路径能力，可延伸至知识管理、个人成长等更广阔的泛学习场景，具备向通用"AI 学习教练"演进的潜力。

### 6.2 商业模式

**（1）基础功能免费 + 高级 AI 功能订阅（Freemium 模式）**

- **免费版**：教材解析、知识图谱、基础练习与掌握度看板，满足入门用户的核心需求，形成流量与口碑；
- **订阅版**：解锁高级 AI 能力——GraphRAG 深度诊断、无限出题额度、主观题 AI 批改、长周期计划等，按月/年订阅；
- **梯度设计**：以"AI 调用成本"为天然分界，成本敏感功能（深度诊断、批量出题）置于付费墙内，保证单位经济模型为正。

**（2）与高校/教辅机构合作的 B 端授权模式**

- 面向高校院系提供课程级部署：教师上传课程教材，全班学生共用图谱与题库，教师端获得班级掌握度驾驶舱；
- 面向教辅出版机构提供内容合作：将教材版权内容转化为交互式学习产品，按课程/学期授权收费；
- 优势：B 端客单价高、续费稳定，且高校场景数据合规边界清晰。

**（3）个性化学习报告与增值服务**

- 面向备考用户提供周期性的《学习诊断报告》（薄弱点分析、掌握度趋势、复习建议），单次付费或含在订阅中；
- 面向家长/教师提供学情报告与督学服务；
- 未来可延伸至 AI 助教按次计费、专家人工答疑对接等增值场景。

StudyMind 的使命，是让每一位学习者拥有一位真正"懂他"的 AI 学习教练。本项目以大语言模型为引擎、知识图谱为骨架、Elo 掌握度模型为标尺、GraphRAG 诊断为闭环，完整实现了"解析—成图—规划—练习—诊断—调整"的个性化学习链路，并以工程化的异步任务架构保证了全流程的流畅体验。作为 23 级人工智能专业课程设计作品，项目不仅覆盖了教材解析、RAG、知识图谱、大模型应用等课程核心知识点，更在"个性化学习路径动态调整"这一创新点上给出了可运行、可演示、可量化的完整方案。我们相信，随着大模型能力的持续演进，StudyMind 所代表的"AI 学习教练"范式将成为未来教育的重要基础设施。
